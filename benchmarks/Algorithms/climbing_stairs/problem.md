# LeetCode 70: Climbing Stairs

## Description

A staircase has $n$ steps. At each move you may climb either one or two steps. Count the distinct ways to reach the top.

## Input

The function receives the number of steps $n$.

## Output

Return the number of distinct ways to reach step $n$.

## Constraints

- $1 \le n \le 45$.
