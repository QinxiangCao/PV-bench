# Bidirectional Selection Sort

## Description

Sort an integer array into nondecreasing order by selecting both an extreme minimum and maximum on each pass.

## Input

The verification-case input consists of an integer array `a` and its length `n`.

## Output

The function produces the same array sorted in nondecreasing order.

## Constraints

- $0 \le n$ and all indices and values fit signed C `int`.
