# Sieve of Eratosthenes

## Description

Classify every integer from 1 through `n` as prime or composite using the Sieve of Eratosthenes.

## Input

The verification-case input consists of an upper bound `n` and writable flag array `f`.

## Output

The function produces prime/composite flags for every integer in the requested range.

## Constraints

- $1 \le n$ and the flag buffer covers indices through `n`.
