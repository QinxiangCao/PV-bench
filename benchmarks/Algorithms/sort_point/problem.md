# Polar-Angle Point Sort

## Description

Sort planar integer points by polar angle around a given reference point, using distance to break collinear ties.

## Input

The verification-case input consists of an array of points and its length; the reference point is supplied by the program state.

## Output

The function produces the same points in polar-angle order.

## Constraints

- All coordinates, cross products, distances, and indices must fit their C integer types.

Classical algorithmic problem reconstructed from the verified C artifact.
