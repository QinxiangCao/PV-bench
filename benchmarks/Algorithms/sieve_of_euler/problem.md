# Euler's Linear Sieve

## Description

Enumerate all prime numbers not exceeding `n` using Euler's linear sieve.

## Input

The verification-case input consists of an upper bound `n` and writable `flag` and `prime` buffers.

## Output

The function produces the prime list and its length.

## Constraints

- $1 \le n$ and both work buffers are large enough for the requested range.
