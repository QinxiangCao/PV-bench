# LeetCode 239: Sliding Window Maximum

## Description

A window of length $k$ begins at the left end of `nums` and moves right one
position at a time. Return the maximum element visible at every position of
the window.

## Input

The function receives an integer array `nums` and a window length $k$.

## Output

Return the maximum element for every window position.

## Constraints

- $1 \le n \le 10^5$.
- $-10^4 \le nums_i \le 10^4$.
- $1 \le k \le n$.
