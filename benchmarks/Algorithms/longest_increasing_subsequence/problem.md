# LeetCode 300: Longest Increasing Subsequence

## Description

Given an integer array `nums`, return the length of its longest strictly
increasing subsequence.

## Input

The function receives an integer array `nums`.

## Output

Return the length of its longest strictly increasing subsequence.

## Constraints

- Original problem: $1 \le n \le 2500$ and $-10^4 \le nums_i \le 10^4$.
- Verification case: $1 \le n \le 10^5$ and a caller-provided DP array of
  length $n$.
