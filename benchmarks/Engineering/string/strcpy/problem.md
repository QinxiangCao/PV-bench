# String Copy

## Problem Description

Copy null-terminated strings, with bounded and unbounded variants.

## Input

The functions receive character pointers and any byte value or length arguments described by their C signatures.

## Output

Each function returns or writes the result prescribed by the corresponding standard string or memory operation.

## Constraints

Strings, byte arrays, capacities, and integer arguments satisfy the validity and bounds stated by each function contract.

## Source

C string-library benchmark adapted by the QCP LLM benchmark suite.
