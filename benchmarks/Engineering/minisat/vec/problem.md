# MiniSat Vector

## Problem Description

Implement dynamically growing integer and pointer vectors in the style used by MiniSat.

## Input

Each function receives a vector object and any size, element, or pointer arguments described by its C signature.

## Output

Operations initialize, inspect, resize, append to, or destroy the vector while preserving its logical contents.

## Constraints

Sizes and capacities satisfy the bounds and allocation conditions stated by the corresponding function contract.

## Source

MiniSat vector implementation adapted by the QCP LLM benchmark suite.
